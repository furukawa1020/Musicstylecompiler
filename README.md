# Music Style Compiler

曲の旋律を音声から採譜し、Christmas、8-bit、Jazz、Classical の4つのスタイルに編曲するWebアプリです。各スタイルで配色、書体、背景、イラスト、楽器編成が切り替わります。

## 起動

Python 3 があれば追加パッケージなしで起動できます。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで [localhost:8000](http://localhost:8000) を開き、デモ曲とスタイルを選びます。「編曲」を押すと、同じ再生位置で原曲と編曲後をA/B切替できます。WAV、MIDI、Music IRと処理時間のJSONも保存できます。

- **デモ** — 「冬のポストカード」と「紙ひこうき」。曲を選ぶと共有用のURLを取得できます。起動中のURLなら [紙ひこうきの例](http://localhost:8000/?demo=paper-kite) をそのまま入力・読込できます。
- **直接音声URL** — 編曲できる権利を持ち、ブラウザで読み込める公開URLを指定します。HTTPS、リダイレクトなし、CORS対応、最大12 MiB。WAV、MP3、M4A、Ogg等の対応はブラウザに依存します。
- **YouTube / YouTube Music** — 公式埋め込みプレーヤーでプレビューします。タイトルと投稿チャンネルはoEmbedで取得できる場合に表示します。埋め込み制限や接続制限がある動画は元のページへのリンクを使えます。YouTubeの音声はコンパイラへ渡しません。

## 変換の範囲

CPU上のWeb Workerが、先頭30秒の音声から支配的な単旋律とテンポを推定します。4/4を仮定し、旋律と調性に合う伴奏の和音を選びます。採譜後の音程、開始、長さを各パスで保持します。複雑なミックスの精密な採譜、ボーカルや原曲の和音の保持、フル尺、Jamendo / Drive連携は今後の対象です。WAVは内蔵シンセの音色です。MIDIの再生音色は再生ソフトの音源に依存します。

GPU・モデル・APIキー・アカウント登録は不要です。音声はブラウザ内で処理し、変換結果はページ内メモリに保持します。外部の音声ホストへの取得とYouTubeのメタデータ・プレビューだけが外部通信します。

## 検証

Node.js 22以上で `node --test` を実行します。2曲×4スタイルの実PCM処理、採譜、旋律保持、異なるWAV、無音・クリッピング、MIDIとURLの処理を検証します。処理時間は実行した端末で異なります。
